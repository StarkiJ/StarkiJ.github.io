1. 哈希冲突与负载因子

哈希将键映射到有限位置；不同键落入同一位置是冲突，不等于键相等。查找先定位桶/探测位置，再按键等价关系确认对象。平均 O(1) 依赖哈希分布与负载，最坏查找可退化到 O(n)。

冲突处理
方法机制注意点
链地址法同桶保存多个条目，再在桶内查找节点开销与局部性；链长受分布影响
开放寻址冲突后按探测规则寻找后续槽位需控制装载；删除不能简单变成“从未使用”，否则截断探测链

负载因子描述元素数量相对桶/槽位数量。rehash 重建映射以改变容量和分布，不是消除所有冲突。开放寻址可使用墓碑或满足探测规则的回移删除；方案必须与查找终止条件配套。

经典问题：哈希值相同能否直接判定同一个对象？

不能。哈希值只是定位线索，仍须比较键。反过来，等价键必须得到一致的哈希值，才能满足哈希容器的使用约束。

参考：C++ 无序容器要求。

2. LRU：查找与淘汰分工

LRU淘汰最近最久未使用的条目。哈希表保存 key→链表迭代器，双向链表按最近使用顺序排列：头部最新、尾部最旧。get 命中和 put 更新都把条目移到头部，超容量删除尾部并同步删除索引。

index[key] → list 节点
list: 最近使用 → … → 最久未使用

核心不变量：每个 key 恰好一个链表节点和一个索引，二者互相对应，元素数不超过容量。list::splice 在同一链表内移动单节点不复制节点，也不使该节点迭代器失效。

get/put 平均 O(1)，空间 O(capacity)；哈希冲突仍可能影响最坏复杂度。示例返回值副本，避免淘汰后使用旧引用；容量为 0 直接不保存。新节点插入索引失败时回滚链表。

经典问题：为什么这个 LRU 不能使用默认拷贝？

索引保存的是链表迭代器。默认分别复制两个容器会让新索引仍指向旧链表节点。示例禁用复制/移动；若要支持复制，应先复制链表，再重建全部索引。

参考：list::splice。

3. 排序复杂度与稳定性

常见比较排序
算法平均 / 最坏时间辅助空间常规实现稳定性
归并排序（数组）O(n log n) / O(n log n)O(n) 缓冲，另有递归栈合并时相等先取左边可稳定
堆排序O(n log n) / O(n log n)O(1)通常不稳定
快速排序O(n log n) / O(n²)朴素递归平均 O(log n)、最坏 O(n)通常不稳定

快速排序若每次先递归较小分区、循环处理较大分区，可把栈深控制在 O(log n)，但不能仅靠这个技巧消除最坏 O(n²) 时间。随机化降低坏划分的发生概率，不是最坏时间保证。

C++17 sort 要求 O(n log n) 比较次数，不应把标准接口与某个朴素快排实现等同。把 key==0 放到末尾又保留有效项顺序，应选择 stable_partition；完整示例见 范围算法与比较器。

4. 循环队列

循环队列在固定数组中复用首尾空间。可维护 head 和 size，容量为 C>0：尾部插入位置为 (head + size) % C，出队后 head 前进一步取模、size 减一；size==0 为空，size==C 为满。

定长环形缓冲区满时可以拒绝、阻塞或覆盖最旧数据，策略由业务定义，不自动“增加节点”。可扩容版本要分配更大数组，按逻辑顺序搬移，令 head=0，并处理旧地址失效。仅用 head==tail 判断时，需留一个空槽或另设满标志来区分空与满。

经典问题：线程安全队列是否只需把 head、tail 改成 atomic？

还需规定元素发布与读取的同步顺序、满/空检查和多生产者/消费者竞争。单生产者单消费者与多方并发是不同设计，不能靠原子下标自动推导正确性。

5. 整数翻转与溢出检查

每次用 x % 10 取末位、x /= 10 去掉末位，再计算 result*10+digit。C++17 的整数除法向零截断，负数余数可为负，因此可以直接处理负输入，不必对 INT_MIN 求绝对值。

计算前检查 result 是否超过上下限的十分之一；相等时再检查最后一位。示例使用 optional 区分“结果为 0”和“溢出失败”，时间 O(d)、空间 O(1)，d 为十进制位数。

经典问题：先乘 10，再发现结果小了来判断溢出，可以吗？

不可以依赖有符号溢出后的值：溢出已经是 UB。必须在运算前证明结果可表示，或在足够宽且已确认范围的类型中计算后再检查。

参考：C++ 整数运算。

6. 最长公共子串与子序列

先明确题目定义
题型状态含义递推
公共子串：必须连续dp[i][j]：以 a[i−1]、b[j−1] 结尾的公共后缀长度字符相同则左上角 +1，否则置 0；全表最大值为答案长度
公共子序列：可跳过字符dp[i][j]：两个前缀的最长公共子序列长度字符相同则左上角 +1，否则 max(上方,左方)

两者均可 O(mn) 时间。子串只需记最大长度和结束位置；滚动数组从右向左更新，避免覆盖上一行的左上角。子序列长度可从左向右滚动并额外保存旧左上角；要输出序列本身，还需恢复路径或其他重建策略。示例按字节处理 std::string，中文文本按字符匹配需要先确定 Unicode 分割单位。

经典问题：原题只写“最大子串”，是否能直接套 LCS 模板？

应确认是否连续、返回长度还是内容、相同最优解如何选择。下面同时给公共子串内容和公共子序列长度的实现，二者不能互换。

7. 实现与边界验证

下载源码（examples.cpp）。使用 C++17 编译；断言测试请勿定义 NDEBUG。

完整实现与断言测试 
#include <algorithm>
#include <cassert>
#include <cstddef>
#include <cstdint>
#include <limits>
#include <list>
#include <optional>
#include <string>
#include <unordered_map>
#include <utility>
#include <vector>

class LRU {
    using Entry=std::pair<int,int>;
    std::size_t capacity_;
    std::list<Entry> order_; // 最近使用在头部
    std::unordered_map<int,std::list<Entry>::iterator> index_;
public:
    explicit LRU(std::size_t capacity) : capacity_(capacity) {}
    LRU(const LRU&)=delete;
    LRU& operator=(const LRU&)=delete;
    LRU(LRU&&)=delete;
    LRU& operator=(LRU&&)=delete;
    std::optional<int> get(int key) {
        auto found=index_.find(key);
        if(found==index_.end()) return std::nullopt;
        order_.splice(order_.begin(),order_,found->second);
        return found->second->second;
    }
    void put(int key,int value) {
        if(capacity_==0) return;
        auto found=index_.find(key);
        if(found!=index_.end()) {
            found->second->second=value;
            order_.splice(order_.begin(),order_,found->second);
            return;
        }
        order_.emplace_front(key,value);
        try { index_.emplace(key,order_.begin()); }
        catch(...) { order_.pop_front(); throw; }
        if(order_.size()>capacity_) {
            index_.erase(order_.back().first);
            order_.pop_back();
        }
    }
    std::size_t size() const noexcept { return order_.size(); }
};
std::optional<std::int32_t> reverse_integer(std::int32_t x) {
    constexpr auto high=std::numeric_limits<std::int32_t>::max();
    constexpr auto low=std::numeric_limits<std::int32_t>::min();
    std::int32_t result=0;
    while(x!=0) {
        const auto digit=x%10;
        x/=10;
        if(result>high/10 || (result==high/10 && digit>high%10)) return std::nullopt;
        if(result<low/10 || (result==low/10 && digit<low%10)) return std::nullopt;
        result=result*10+digit;
    }
    return result;
}
std::string common_substring(const std::string& a,const std::string& b) {
    std::vector<std::size_t> dp(b.size()+1);
    std::size_t length=0,end=0;
    for(std::size_t i=1;i<=a.size();++i) {
        for(std::size_t j=b.size();j>0;--j) {
            dp[j]=(a[i-1]==b[j-1] ? dp[j-1]+1 : 0);
            if(dp[j]>length) { length=dp[j];end=i; }
        }
    }
    return a.substr(end-length,length);
}
std::size_t common_subsequence_length(const std::string& a,const std::string& b) {
    std::vector<std::size_t> dp(b.size()+1);
    for(char x : a) {
        std::size_t previous_diagonal=0;
        for(std::size_t j=1;j<=b.size();++j) {
            const auto previous_row=dp[j];
            dp[j]=(x==b[j-1] ? previous_diagonal+1 : std::max(dp[j],dp[j-1]));
            previous_diagonal=previous_row;
        }
    }
    return dp.back();
}
int main() {
    LRU cache(2);
    cache.put(1,10);cache.put(2,20);
    assert(cache.get(1)==10);
    cache.put(3,30);assert(!cache.get(2));
    cache.put(1,11);cache.put(4,40);
    assert(!cache.get(3) && cache.get(1)==11 && cache.get(4)==40 && cache.size()==2);
    LRU empty(0);empty.put(1,1);assert(!empty.get(1) && empty.size()==0);
    LRU one(1);one.put(1,1);one.put(1,9);assert(one.get(1)==9);
    one.put(2,2);assert(!one.get(1) && one.get(2)==2);
    assert(reverse_integer(12345)==54321);
    assert(reverse_integer(1200)==21);
    assert(reverse_integer(-120)==-21);
    assert(reverse_integer(0)==0);
    assert(!reverse_integer(1534236469));
    assert(!reverse_integer(std::numeric_limits<std::int32_t>::min()));
    assert(reverse_integer(1463847412)==2147483641);
    assert(reverse_integer(-2147483412)==-2143847412);
    assert(common_substring("xabcdz","yabcdw")=="abcd");
    assert(common_substring("abc","XYZ").empty());
    assert(common_substring("","abc").empty());
    assert(common_substring("aaaa","aa")=="aa");
    assert(common_subsequence_length("abcde","ace")==3);
    assert(common_subsequence_length("abc","abc")==3);
    assert(common_subsequence_length("abc","XYZ")==0);
    assert(common_subsequence_length("","a")==0);
}
