    计算机基础

    5 篇

    围绕数据结构、操作系统、计算机组成与网络建立基础，并以 ARM64 MTE 专题理解硬件与软件协作的内存安全机制。

    综述

    • 数据结构基础

      从操作成本出发，理解动态数组、链表、堆、红黑树和哈希表的结构与维护。

      章节直达

      • 操作需求与复杂度
      • 动态数组与链表
      • 栈、队列与堆
      • 搜索树与红黑树
      • 哈希表与冲突处理
      • 结构选择与语言接口

    • 操作系统基础

      从进程与系统调用，到地址转换、TLB、缓存、缺页和 mmap，再理解通信、同步与信号。

      章节直达

      • 进程、线程与调度
      • 系统调用与 ARM64 约定
      • 虚拟内存与堆栈
      • 完整访存流程
      • mmap 与按需触页
      • 进程创建与写时复制
      • 进程间通信
      • 锁、futex 与死锁
      • 异常、信号与故障

    • 计算机组成：ISA、流水线与缓存

      区分 ISA 与微架构，用 RISC-V 流水线理解冒险，比较 x86-64 / AArch64，并解释缓存一致性与伪共享。

      章节直达

      • ISA 与微架构
      • RISC-V 流水线
      • x86-64 / AArch64 ISA
      • 缓存一致性与伪共享

    • 网络基础

      从端点与字节流出发，理解可靠传输、消息边界以及 HTTP/HTTPS。

      章节直达

      • 分层与通信端点
      • TCP 可靠传输
      • UDP 与传输选择
      • socket 收发与消息边界
      • HTTP 与 HTTPS
      • 一次 HTTPS 请求
