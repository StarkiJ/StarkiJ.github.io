阅读范围与实现边界

托管运行时先把程序表示变成可用的类型与方法，再协调执行、线程与内存管理。本篇沿字节码、类身份、初始化、调用、同步和执行状态展开；对象如何分配与回收见托管内存，优化机器码如何生成见编译器。

共同语义以 Java SE 21 的语言与虚拟机规范为参照，HotSpot 示例限定 JDK 21；Android 对照采用 ART / Android 14 的常规应用场景。ART 使用 DEX，不能直接套用 class 文件、HotSpot 元数据或全部 Java SE API。JDK 虚拟线程也不等同于 Android 平台线程或 Kotlin 协程。
