5. 拷贝、值类别与移动语义

5.1 拷贝语义与特殊成员函数

特殊成员函数包括默认构造、析构、拷贝构造/赋值和移动构造/赋值。编译器按规则自动提供部分操作；= default 请求默认实现，= delete 明确禁用操作。移动表示转交资源，接着阅读本章的值类别与std::move。

复制操作
概念含义
拷贝构造用已有对象建立新对象，例如 T b = a;。
拷贝赋值替换已有对象状态，例如 b = a;，还须处理旧资源与自赋值。
浅拷贝复制成员值；裸指针只复制地址，多个对象可能指向同一资源。
深拷贝建立独立资源副本，修改一份不影响另一份。

资源所有权（谁负责释放）决定复制策略。独占裸资源的类若保留默认地址拷贝，可能重复释放；交给 vector 等成员管理时，可复用成员的复制行为。

Rule of Zero 建议把资源交给成员管理，避免自己编写清理和复制逻辑。Rule of Three/Five 提醒手工管理资源时配套考虑析构、拷贝构造/赋值，以及移动构造/赋值。自行声明析构函数会阻止隐式生成移动构造和移动赋值。

5.2 值类别与引用

表达式是一次求值的语法单位，例如 n、a+b、f()。它既有类型，也有值类别；后者区分是否标识对象、是否可参与资源复用，影响引用绑定与拷贝/移动选择。

表达式的值类别
类别常见示例含义
左值 lvalue变量名表达式 obj标识一个对象或函数，具有可识别的身份。
纯右值 prvalue42、T{}用于计算值或初始化对象。
将亡值 xvaluestd::move(obj)标识可参与资源复用的对象。

lvalue 与 xvalue 都标识对象或函数，合称泛左值 glvalue；prvalue 与 xvalue 合称右值 rvalue。类别属于表达式，不是对象永久的属性；同一对象用名字访问是左值，用 std::move 包装后可得到将亡值。

T& 是左值引用；T&& 是右值引用，通常绑定右值；const T& 也能绑定右值。但右值引用变量一旦有名字，通过这个名字访问时仍是左值表达式。

移动语义允许目标对象接管源对象的资源，并让源对象保持约定状态。移动构造建立新对象；移动赋值还需处理目标旧资源。成本取决于类型实现，不保证总是常数时间。

5.3 std::move 与移动后状态

std::move 是类型转换，不执行资源转移。它通常将表达式转为将亡值；是否移动取决于后续重载选择及其实现。

Item a;
const Item b;
Item x = std::move(a);  // 可匹配 Item(Item&&)
Item y = std::move(b);  // 得到 const Item&&，通常改走拷贝

const 不会被 move 去掉。常规移动构造接收非 const 的 T&&，以便调整源状态；const 右值不能绑定它，却可绑定拷贝构造的 const T&。

移动后状态：标准库类型通常保持“有效但未指定”，除非另有明确保证。可析构，可执行满足前提的操作；不能假定所有 string/vector 都为空。unique_ptr 移动后为空是其明确保证。

代码示例：const 对象的 move 与实际拷贝
经典问题：为什么 std::move 一个 const 对象，仍可能发生拷贝？

move 保留 const，const T&& 通常不能绑定到 T&& 移动构造参数，但可绑定到 const T& 拷贝参数。是否移动必须看实际可用重载。

5.4 拷贝消除、NRVO 与 noexcept

拷贝消除让对象直接构造在最终位置，省掉中间的拷贝或移动。NRVO（命名返回值优化）允许把符合条件的具名局部对象直接构造为返回结果；它与下面 C++17 保证的同类型纯右值返回不同。

返回对象时的构造
写法C++17 下的规则
return T{};此类同类型纯右值可直接构造结果对象，不需要可用的拷贝/移动构造。
return local;命名返回值优化 NRVO 允许但不强制；未消除时可按规则尝试移动。
return std::move(local);可能破坏 NRVO 的适用条件，通常不应随手添加。

vector 与 noexcept：重分配时，若移动可能抛异常且类型可拷贝，实现常选择拷贝以维持强异常保证；不抛异常的移动更适合迁移。只有可抛移动、没有可用拷贝时，特定异常保证会减弱。move_if_noexcept 表达类似选择。
